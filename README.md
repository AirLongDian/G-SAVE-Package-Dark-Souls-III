# G-SAVE · DARK SOULS III Support Package

用于 [G-SAVE](https://github.com/AirLongDian/G-SAVE) 的 DARK SOULS III 支持包。

手动配置时选择：

- EXE：`<Steam库>\steamapps\common\DARK SOULS III\Game\DarkSoulsIII.exe`
- 存档文件夹：`%APPDATA%\DarkSoulsIII`

选择的文件夹内应直接包含一个或多个 Steam 账号数字目录，账号目录内才是 `DS30000.sl2`。
不要选择账号数字目录或单个存档文件。支持包解析全部账号的 10 个角色槽位。

---

DARK SOULS III support package for [G-SAVE](https://github.com/AirLongDian/G-SAVE).

When configuring paths manually, select:

- EXE: `<Steam Library>\steamapps\common\DARK SOULS III\Game\DarkSoulsIII.exe`
- Save folder: `%APPDATA%\DarkSoulsIII`

The selected folder must directly contain one or more numeric Steam account folders; each account folder contains `DS30000.sl2`. Do not select an account folder or an individual save file. The package parses all 10 character slots for every account.
